# 内部事项提醒

归属：四三九九 / 平台管理；菜单：辅助功能管理 > 内部事项提醒。
本功能供公司内部人员使用。新增和编辑抽屉在标题正下方、与标题左缘对齐显示灰色说明：“用于公司内部事项提醒，仅向下方填写的邮箱发送邮件。”此说明界定业务用途和通知渠道，不代表已增加企业邮箱域名限制。
使用 design-backoffice-ui 固定模板，单卡片列表，新增和编辑使用38%小抽屉。
列表列为提醒标题、提醒时间、状态、创建时间、操作，不展示邮箱。查询支持标题、日期范围，状态在表头筛选。
状态仅待发送、已发送。操作列包含编辑、删除，只有待发送且未到期的任务可操作；已发送行显示“-”。不提供详情、取消提醒、重发或恢复入口。删除使用小抽屉二次确认，显示提醒标题与删除后不再发送、无法恢复的提示。提交时重新校验状态和发送时刻，成功后从列表及本地存储移除，显示绿色删除成功提示；保存失败保留原数据，分页自动修正到有效页。
表单包含标题（100字）、纯文本正文（5000字）、每行一个的多个邮箱、单个提醒日期，固定北京时间09:00。必填、格式、去重及提交时刻校验。
到期在页面打开时模拟发送，不实际调用邮件服务。本地存储键 notification-reminders-v1，刷新保留修改。旧的失败和取消记录在加载时排除，不转换为其他状态。新模拟数据仅包含待发送和已发送。
原型入口 annotation-demo，页面路由 auxiliary/reminders，不新增依赖、不修改公共模板。

新增、编辑提交时，空字段分别在对应控件下方显示“邮件标题不能为空”“邮件正文不能为空”“收件邮箱不能为空”“提醒日期不能为空”，同时显示红色 Toast“请完善信息”。用户修改字段后清除该字段提示。抽屉内不展示“请完善所有信息”等全局错误文案；邮箱格式和日期规则错误也显示在对应字段下方。


新增、编辑表单不单列发送时间；提醒日期控件下方显示灰色说明“于所选日期上午09:00发送一次。仅可选择明天及以后的日期。”，与日期控件左侧对齐。


列表操作区不展示“演示数据，不实际发送邮件”说明；原型仍使用本地模拟发送。
主列表在创建时间之后、操作之前展示“操作人”。新增及编辑时记录当前演示管理员；模拟发送不覆盖操作人。历史本地演示数据缺失该字段时补为演示管理员。

抽屉用途说明独立于编辑表单，作为整页提示保留在标题下方；说明与表单间距28px，使编辑区域适当下移。新增、编辑使用相同布局。

新增、编辑抽屉的提醒日期选择器宽度为200px，有值与无值保持同宽，完整显示日期占位文字。

提醒日期严格大于系统当天（沿用北京时间口径）。日期控件通过可选disabledDate接口将今天及过去日期置灰并使用原生disabled禁止选择；保存时再次验证日期。列表日期范围筛选不受限制。
